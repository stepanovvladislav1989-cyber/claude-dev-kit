# claude-dev-kit

Метод разработки с Claude Code для одного человека — доменного эксперта, который не программист. Автор пишет правила и принимает решения, весь код пишет ИИ-агент, после каждой задачи его проверяет отдельный субагент-ревьюер, а замки (хуки) держат обязательные правила автоматически.

Собран для собственного пилотного проекта, но правила и замки не зависят от предметной области — подходят для любого проекта одного человека с Claude Code.

## С чего читать

1. [СПРАВОЧНИК.md](СПРАВОЧНИК.md) — полное описание метода: роли, этапы, замки, границы применимости.
2. [УСТАНОВКА.md](УСТАНОВКА.md) — установка на Windows, 30–40 минут один раз.
3. [ШПАРГАЛКА.md](ШПАРГАЛКА.md) — короткая памятка на каждый день после установки.

## Что внутри

```
global/            → копируется в ~/.claude/, действует во всех проектах
  CLAUDE.md           правила общения, стоп-лист, выбор модели
  agents/             субагенты reviewer (только чтение) и implementer
  hooks/guard.py       замок: пароли, опасные команды, разовые правки базы
  skills/              допрос, устройство, нарезка задач, один тикет, ревью, проверка
project-template/  → репозиторий-шаблон для новых проектов на GitHub
  .claude/hooks/       защита тестов и эталона, запрет заканчивать с красной проверкой
  scripts/             единая проверка, дорожная карта, выгрузка кода задачи для разбора
  .github/workflows/   та же проверка на сервере GitHub
```

## Известное ограничение

Метод рассчитан на одного пользователя и один компьютер: замки — это защита от ошибки, не от целенаправленного обхода. Подробнее о границах применимости — раздел 10 [СПРАВОЧНИК.md](СПРАВОЧНИК.md).
