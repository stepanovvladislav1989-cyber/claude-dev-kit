# Журнал решений

Решения не переписываются. Новое решение — новая запись, старое помечается «заменено Р-…».

Формат:

```
### Р-01. Короткое название (дата)
Контекст: почему встал вопрос.
Варианты: что рассматривали.
Решение: что выбрали и почему.
Последствия: что это меняет.
Статус: действует | заменено Р-…
```
