## Правила

Формат (заголовок с номером обязателен; пример на цифрах становится тестом):

```
### ПР-01. Короткое название
Источник: ТЗ п. … / решение Р-…
Правило: …
Пример: вход … → ожидаемый результат …
Статус: черновик | утверждено | отменено (см. Р-…)
```
