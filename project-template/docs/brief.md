# Бриф: задача словами заказчика

**Дата:**

Единственный документ, который пишет заказчик. Агент вставляет текст **дословно** — без правок, сокращений и пересказа — и только нумерует абзацы: Б-1, Б-2… Каждое требование ТР цитирует свой абзац, так видно, что из брифа ничего не потерялось (`check_docs.py` предупредит об абзаце, который не попал ни в один документ). Дополнение — новым абзацем со следующим номером и датой; старые абзацы не переписываются.

Формат:

```
Б-1. Текст первого абзаца, как его сказал или написал заказчик.

Б-2. (2026-11-05) Дополнение, добавленное позже.
```
