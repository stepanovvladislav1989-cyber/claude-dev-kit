# Тесты-приёмка

Тесты по **вашим сценариям** — их пишет агент. Свои проверки можно добавить словами в файл задачи, раздел «Мои тесты до сессии» (агент спросит об этом при утверждении сценариев).

Новые файлы агент создаёт сам (по утверждённым сценариям). Изменить или удалить существующий файл — только с вашего разрешения: Claude Code покажет запрос. То же для `tests/e2e/` и `tests/golden/`.

Как называть тесты — скилл `ticket`, шаг «Падающие тесты».
