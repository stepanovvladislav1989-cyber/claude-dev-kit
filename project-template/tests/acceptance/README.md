# Тесты-приёмка

Тесты по **вашим сценариям**. Сюда же можно положить **свои тесты до сессии** и перечислить их в файле задачи, раздел «Мои тесты до сессии» — агент включит их в работу как есть.

Новые файлы агент создаёт сам (по утверждённым сценариям). Изменить или удалить существующий файл — только с вашего разрешения: Claude Code покажет запрос. То же для `tests/e2e/` и `tests/golden/`.

Имя теста содержит номер правила или задачи: `test_pr07_...`, `test_t012_...`.
