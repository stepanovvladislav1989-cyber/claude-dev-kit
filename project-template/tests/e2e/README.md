# Сквозные тесты (e2e)

Проверка всей цепочки «от данных до результата»: загрузили данные → система посчитала → на выходе (отчёт, экран, выгрузка) правильные цифры.

Запускаются отдельной строкой в `python scripts/validate.py`, поэтому в отчёте видно «e2e: зелёных X из Y».
Как называть тесты — скилл `ticket`, шаг «Падающие тесты».
