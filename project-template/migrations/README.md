# Миграции базы данных

Все изменения данных и структуры базы — только файлами здесь. Разовые команды в терминале, которые меняют данные, запрещены: они не попадают в историю, ревью и выгрузку для разбора.

- Файлы нумеруются по порядку: `001_…`, `002_…`. Применённый файл не правится — нужна правка, значит новый файл.
- Запуск — только командой «бэкап + миграция» из `CLAUDE.md` проекта (её настраивает `design`).
- Разовая правка данных (например, исправить ошибочные суммы) — тоже отдельным файлом миграции.
