----- ПРОМТ -----

Разверни в этой папке новый проект по моему методу claude-dev-kit.

Шаблон возьми с GitHub: https://github.com/stepanovvladislav1989-cyber/claude-dev-kit
Раздел Releases, файл project-template.zip из последнего релиза. Не бери «Source code», там весь репозиторий.

Дальше по шагам:
1. Распакуй шаблон в эту папку.
2. Сделай git init и первый коммит.
3. Создай новый приватный репозиторий на GitHub под именем папки и отправь туда код.
4. Установи зависимости (pip install -r requirements.txt) и pre-commit (pre-commit install).
5. Запусти python scripts/validate.py, должно быть ПРОШЛО.
6. Запусти /new-project.
