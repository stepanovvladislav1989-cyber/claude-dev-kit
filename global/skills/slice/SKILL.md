# slice — задачи и сценарии пакетом

Итог: файлы `docs/tickets/Т-001-кратко.md` … по шаблону `_template.md`, со сценариями, утверждёнными пользователем.

## 1. Нарезка

- **Вертикальный срез:** работающий кусок «от данных до результата».
- **Размер:** одна проверяемая вещь, одна фраза, примерно до 5 файлов.
- Ссылки на ТР и ПР **по номерам**, текст правил не копируется.
- **Релиз:** проставь каждой задаче номер и название релиза (`**Релиз:** 2. Упр. учёт`) — части, которую можно внедрить и эксплуатировать отдельно.
- **Вид задачи:** 💰 — затрагивает деньги, расчёты, правила, удаление данных; остальное — обычная. Сомневаешься — 💰.
- **Сложность:** низкая / обычная / высокая — по критериям «Выбор модели» глобальных правил. От неё зависит, какая модель пишет код. Сомневаешься — выше.
- **Не входит в задачу:** что соседнее и заманчивое делать не будем — одной-двумя строками в разделе задачи.

## 2. Порядок

1. Т-001 — «скелет»: минимальный сквозной путь на одном простом случае.
2. Затем самое рискованное, пока кода мало.
3. Остальное по зависимостям.

## 3. Черновики сценариев — для всех задач сразу

- Для каждой задачи — 3–6 сценариев «при таких данных → ожидаю такой результат», из примеров на цифрах в ПР. Обязательно — что система должна **отклонить**.
- Крайние случаи агента — отдельным списком в той же задаче.

## 4. Сверка перед утверждением

Перечитай требования, правила и черновики задач и найди (только читая, ничего не исправляя молча):
- ТР без задачи и задачи без ТР (`check_docs.py` тоже предупредит о ТР без задачи);
- одно понятие названо по-разному в разных документах; противоречия между ПР и сценариями;
- расплывчатые слова без цифр («быстро», «много», «обычно»);
- оставшиеся маркеры `[УТОЧНИТЬ: …]`.
Находки — исправь в документах сам, если это не меняет ПР/ТР; иначе — вопросы пользователю пакетом вместе с утверждением.

## 5. Утверждение одним пакетом

- Покажи пользователю: таблица задач (номер · вид · сложность · одна фраза · зависит от), затем сценарии по задачам, кратко.
- В том же сообщении — один вопрос: «Хотите добавить свои проверки к какой-нибудь задаче? Напишите словами „при таких данных → такой результат“ или ответьте „нет“» (рекомендую «нет»: утверждённые сценарии и есть ваши тесты). Ответ впиши в раздел «Мои тесты до сессии» нужной задачи.
- Пользователь отвечает одной фразой: «утверждаю всё» или «всё, кроме …».
- Отметь в задачах «Сценарии: утверждены». Большой проект — утверждай порциями по 5–10 задач, не всё за раз.
- Собери дорожную карту `python scripts/roadmap.py`. `python scripts/validate.py` → ПРОШЛО, коммит `docs: план задач и сценарии`.
